# STM32CubeIDE 설치 (2.1.1)

STM32CubeIDE는 STM32 프로젝트의 코드 작성, 빌드, 보드 다운로드, 디버깅에 사용하는 통합 개발 환경입니다.

이 문서에서는 **Windows 10/11 64비트 환경에서 STM32CubeIDE 2.1.1을 설치하는 방법**을 설명합니다. 이번 과정의 참고 코드는 이 버전에서 빌드·보드 검증을 진행했습니다.

## 1. 설치 전에 알아둘 내용

이번 과정에서는 다음 두 프로그램을 함께 사용합니다.

| 프로그램 | 강의 버전 | 용도 |
| --- | --- | --- |
| STM32CubeMX | 6.17.0 | 핀·클럭·주변장치 설정, 초기화 코드 생성 |
| STM32CubeIDE | 2.1.1 | 코드 작성, 빌드, 다운로드, 디버깅 |

**STM32CubeIDE 2.x에서는 CubeMX를 별도로 설치해 사용합니다.** 이전 버전의 강의 영상에서 보이는 IDE 내부 핀 설정 화면이 없더라도 설치 오류가 아닙니다. CubeMX 설치는 [STM32CubeMX 설치 안내](STM32CubeMX_설치.md)를 참고합니다. [ST의 CubeIDE 2.0 변경 안내](https://community.st.com/stm32cubeide-mcus-28/stm32cubeide-2-0-release-early-heads-up-152682)

설치 단계에서는 보드를 연결하지 않아도 됩니다.

## 2. 설치 파일 다운로드

1. [STM32CubeIDE 공식 페이지](https://www.st.com/en/development-tools/stm32cubeide.html)에 접속합니다.
2. **Get Software** 영역에서 Windows용 **STM32CubeIDE-Win**을 찾습니다.
3. **All versions** 또는 버전 선택 목록에서 **2.1.1**을 선택합니다.
4. 라이선스 약관을 확인하고 다운로드합니다. 로그인이나 이메일 확인을 요청하면 화면 안내에 따라 진행합니다.

> **Get latest**를 누르면 강의와 다른 버전이 다운로드될 수 있습니다. 다운로드 전에 **2.1.1**인지 확인해 주세요. 이번 안내는 독립 실행형 STM32CubeIDE 기준입니다.

ZIP 파일로 내려받았다면 압축을 모두 해제한 뒤 폴더 안의 Windows용 설치 실행 파일(`.exe`)을 사용합니다. 파일 이름에는 버전 외에 빌드 번호나 날짜가 포함될 수 있습니다.

## 3. 설치 프로그램 실행과 경로 선택

1. 설치 프로그램을 실행합니다.
2. Windows에서 실행 권한을 확인하면 게시자가 **STMicroelectronics**인지 확인하고 허용합니다.
3. 설치 마법사에서 **Next**를 누르고 라이선스 내용을 확인합니다.
4. 약관에 동의한 뒤 설치 경로를 선택합니다.

설치 경로는 기본값을 사용해도 됩니다. 직접 지정한다면 `C:\ST\STM32CubeIDE_2.1.1`처럼 버전을 구분할 수 있는 위치를 사용할 수 있습니다.

이 경로는 프로그램 설치 위치입니다. 코드를 저장할 **프로젝트 폴더**나 IDE의 작업 정보를 저장할 **Workspace**와는 구분합니다.

## 4. ST-LINK 드라이버 선택과 설치

구성 요소 선택 화면에서 **ST-LINK drivers**가 선택되어 있는지 확인합니다. 이번 과정에서는 NUCLEO-F446RE에 내장된 ST-LINK로 프로그램을 다운로드하고 디버깅합니다.

**SEGGER J-Link drivers** 항목도 표시될 수 있지만, 이번 과정에서 사용하는 디버거는 ST-LINK입니다.

설정을 확인한 뒤 **Install**을 눌러 설치합니다. 별도의 드라이버 설치 창이 나오면 제공자를 확인하고 완료까지 진행합니다. 모든 설치가 끝나면 마법사를 종료합니다. [ST 공식 설치 가이드](https://www.st.com/resource/en/user_manual/dm00603964-stm32cubeide-installation-guide-stmicroelectronics.pdf)

## 5. 첫 실행과 Workspace 선택

Windows 시작 메뉴에서 **STM32CubeIDE**를 검색해 실행합니다.

처음 실행할 때 Workspace 선택 창이 표시되면 강의용 폴더를 지정하고 **Launch**를 누릅니다. 예를 들어 `C:\STM32Course\workspace`를 사용할 수 있습니다.

Workspace는 프로젝트 목록, 편집기 상태, 디버그 설정 등 IDE의 작업 정보를 관리하는 공간입니다. 프로젝트 소스는 다른 폴더에 두고 가져와서 사용할 수 있습니다.

| 구분 | 경로 예시 | 저장하는 내용 |
| --- | --- | --- |
| Workspace | `C:\STM32Course\workspace` | IDE 작업 정보와 설정 |
| 참고 저장소 | `C:\STM32Course\stm32f446-course-examples` | Git으로 내려받은 강의별 프로젝트 코드 |

위 경로는 예시이며 그대로 사용해도 됩니다. 경로 문제를 줄이기 위해 짧은 영문 폴더명을 권장합니다. Workspace와 참고 저장소는 별도 폴더로 관리합니다.

다른 CubeIDE 버전에서 쓰던 Workspace가 있다면 이번 강의용 Workspace를 새로 만드는 것을 권장합니다. 시작 화면이 표시되면 **Workbench**로 이동해 편집 화면을 엽니다.

## 6. 설치 버전 확인

1. 메뉴에서 **Help → About STM32CubeIDE**를 엽니다.
2. 표시된 버전이 **2.1.1**인지 확인합니다.
3. 여러 버전이 설치되어 있다면 실행한 바로가기와 설치 경로를 확인합니다.

강의 진행 중 업데이트 안내가 표시되더라도 별도 안내가 있을 때까지 **2.1.1을 유지**합니다.

## 7. 설치 완료 확인

- [ ] STM32CubeIDE가 정상적으로 실행됩니다.
- [ ] 설치 버전이 **2.1.1**입니다.
- [ ] 지정한 Workspace에서 편집 화면을 열 수 있습니다.
- [ ] 설치 과정에서 **ST-LINK drivers** 설치를 완료했습니다.

여기까지는 프로그램 설치 확인입니다. **프로젝트 빌드와 보드 연결·다운로드 확인은 08강에서 별도로 진행합니다.** IDE가 실행된다는 것만으로 보드 연결까지 확인된 것은 아닙니다.

## 설치 중 문제가 생겼다면

| 증상 | 확인할 내용 |
| --- | --- |
| 설치 파일이 실행되지 않음 | ZIP 압축을 모두 해제했는지, Windows용 파일을 받았는지 확인합니다. 다운로드가 중단됐다면 공식 페이지에서 다시 받습니다. |
| Workspace를 열 수 없거나 사용 중이라는 메시지가 나옴 | 같은 Workspace를 사용하는 CubeIDE가 이미 실행 중인지 확인합니다. 필요한 경우 다른 빈 폴더를 Workspace로 선택합니다. |
| 실행 버전이 2.1.1이 아님 | 다른 버전의 바로가기를 실행했는지 확인합니다. |
| 이후 실습에서 ST-LINK가 인식되지 않음 | 데이터 통신이 가능한 USB 케이블과 보드의 ST-LINK USB 연결을 확인합니다. 드라이버가 누락됐다면 [ST-LINK 공식 드라이버](https://www.st.com/en/development-tools/stsw-link009.html)를 확인합니다. |

해결되지 않으면 **오류 메시지와 발생한 설치 단계**를 함께 강사에게 전달해 주세요.
